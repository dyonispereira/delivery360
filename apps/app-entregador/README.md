# App do entregador (iOS e Android)

Será criado com React Native + Expo nas **Sprints 4 e 5** (ver `docs/plano-de-desenvolvimento.md`).

Funções previstas:
- Login por convite vinculado a um ou mais restaurantes.
- Receber lotes de entrega (notificação push), confirmar retirada.
- Ordem das entregas, navegação no Waze/Google Maps.
- Finalizar cada entrega digitando os 4 últimos dígitos do telefone do cliente (validado no servidor).
- Envio da localização durante a rota; histórico e ganhos.

Usará a mesma API (`apps/api`) e os tipos de `packages/shared`.
