# App do gerente (iOS e Android)

Será criado com React Native + Expo nas **Sprints 8 e 9** (ver `docs/plano-de-desenvolvimento.md`).

Funções previstas:
- Indicadores do dia (faturamento, pedidos, ticket médio, tempo de preparo e entrega).
- Pedidos ao vivo e alertas.
- Resultado do mês (DRE) quando o módulo Gestão estiver ativo.

O menu respeita as mesmas chaves de módulo do sistema web (`GET /tenant/context`).
